# Постскриптум

**Постскриптум** — это веб-приложение мессенджер, полностью стилизованное под **старинные рукописные письма** и атмосферу прошлого века. Проект «для мечтателей» возвращает романтику бумажной переписки в цифровую эпоху.

⚠️ **Обратите внимание:** На данный момент проект находится в **активной разработке** и готов не полностью. Многие функции и элементы интерфейса находятся в процессе создания.

**Демо проекта:** [Посмотреть на Netlify](https://unrivaled-bavarois-71e6c3.netlify.app/)

## Команды для запуска и сборки

Для работы с проектом вам понадобится установленный Node.js

### Установка зависимостей

Перед первым запуском установите все необходимые пакеты:

```bash
npm install
```

### Запуск локального сервера:

```bash
npm run dev
```

После запуска проект доступен на порту `3000`

### Сборка для продакшена

Создание оптимизированной финальной сборки проекта в папку `dist`:

```bash
npm run build
```
